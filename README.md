## ✨ Overview

Altitude Beverages is a frontend-focused beverage brand experience designed around a strong visual identity and interactive product presentation.

The project explores how modern frontend technologies can be used to create a website that feels more like a **digital brand experience** than a traditional product page.

The focus was on:

* Immersive hero sections
* Product-focused visual storytelling
* Smooth page transitions
* Interactive hover experiences
* Motion and micro-interactions
* Video and image-based visual content
* Responsive layouts
* Clean component-based React architecture

---

## 🚀 Features

### 🎬 Immersive Hero Experience

A visually rich landing section designed to immediately establish the brand identity using media, typography, motion, and layered content.

### 🥤 Interactive Product Showcase

Product sections use interactive visuals and animations to make the different beverage products feel more engaging.

### 🖱️ Hover Interactions

Custom hover galleries and interactive elements create dynamic visual feedback as users explore the website.

### 🔄 Page Transitions

Custom transition components provide smoother navigation between different sections and pages.

### ⚡ Preloader & Loading Experience

A dedicated preloader creates a more polished entry experience before the main interface appears.

### 🔊 Interactive Sound

Custom sound utilities are used to add subtle audio feedback to selected interactions.

### 📱 Responsive Design

The interface is designed to adapt across different screen sizes while maintaining the visual hierarchy of the experience.

### 🛍️ Shop Experience

Includes dedicated shop/product sections for presenting the beverage lineup in a more structured shopping-style interface.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ADWAITC7/altitude-beverages.git
```

### 2. Navigate into the project

```bash
cd altitude-beverages
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

---

## 🏗️ Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🎨 Design Direction

The visual direction of the project is built around a **bold, energetic, premium beverage aesthetic**.

Rather than treating the website as a simple catalog, the interface focuses on:

**Brand → Motion → Product → Interaction → Experience**

This approach was used to make the product itself feel like the centerpiece of the website.
